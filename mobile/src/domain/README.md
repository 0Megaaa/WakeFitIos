# Domain Layer

## Responsibilities

- Alarm and AlarmTrigger models
- ChallengeSession state machine
- Workout model
- Exercise model
- Streak model
- Exercise counting rules
- Pure business models

## Constraints

- Must use pure TypeScript only
- MUST NOT depend on React
- MUST NOT depend on React Native
- MUST NOT depend on Expo
- MUST NOT depend on Android
- MUST NOT depend on iOS
- MUST NOT directly access API
- MUST NOT directly access database
- MUST NOT use Platform.OS
